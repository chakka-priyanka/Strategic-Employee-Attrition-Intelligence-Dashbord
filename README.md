Strategic Employee Attrition Intelligence Dashboard

📝 Introduction

The Strategic Employee Attrition Intelligence Dashboard is a Power BI-based workforce analytics project developed to understand employee attrition and identify patterns related to employee retention, performance, career growth, workload, and work arrangements.

The project transforms employee-level workforce data into interactive dashboards and analytical reports, allowing users to explore employee attrition from different perspectives.

🎯 Objectives

The main objectives of this project are:

- Analyze overall and segment-level employee attrition.
- Identify patterns associated with burnout, overtime, salary growth, tenure, and performance.
- Analyze attrition across departments, job roles, and work modes.
- Develop interactive Power BI dashboards and reports.
- Provide insights to support employee retention and workforce analysis.

⚠️ Problem Statement

The organization has 5,000 employees, of which 895 employees have left, resulting in an overall attrition rate of 17.9%.

The project focuses on understanding how factors such as compensation, workload, employee engagement, career progression, performance, and work arrangements are associated with employee attrition.

The objective is to convert workforce data into meaningful KPIs and interactive visual analysis that can help identify areas requiring further investigation.

🔄 Project Methodology

The project follows a complete data analytics workflow:

Data Collection → Data Quality Checking → Data Exploration → Preprocessing → SQL Analysis → Power BI Development → DAX Calculations → Dashboard & Report Development → Testing → Insights

The data was reviewed for missing values, categorical consistency, numerical fields, attrition status, and duplicate employee records before visualization development.

📊 Dashboard & Reports

Dashboard

The Power BI dashboard provides an interactive view of workforce and attrition information.

It includes analysis of:

- Department-wise attrition
- Job-role-wise attrition
- Work-mode analysis
- Salary-growth bands
- Education background
- Tenure and career levels
- Overtime
- Performance levels

Interactive filters are provided for Education Level, Work Mode, Gender, and Marital Status.

Report 1 — Employee Retention Performance Intelligence

This report focuses on burnout, employee engagement, work-life balance, manager support, salary growth, work mode, education, tenure, and career levels.

Report 2 — Employee Performance Career Growth Intelligence

This report focuses on performance rating, manager support, work experience, overtime, training investment, career stages, and department-wise attrition.

Strategic Workforce Analysis

This view provides an overall workforce perspective using total employees, employees who left, attrition rate, average experience, average overtime, and AI adoption rate, together with department, job-role, and work-mode analysis.


💡 Key Insights

The dashboard provides several descriptive observations:

- Overall employee attrition is 17.9%.
- Attrition differs across salary-growth bands.
- Different overtime groups show different displayed attrition levels.
- Attrition varies across performance ratings.
- Attrition differs across onsite, hybrid, and remote work models.
- Attrition varies across career levels and tenure.
- Departments and job roles show different attrition patterns.
- AI adoption is included as a workforce indicator.

These observations represent patterns in the available dataset and do not by themselves establish that any particular factor causes employee attrition.
